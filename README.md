FairSight AI is an AI-driven platform designed to evaluate datasets across multiple critical factors, ensuring data fairness, quality, and readiness for machine learning applications. It combines advanced analytics, user-friendly interfaces, and monetization features to offer a comprehensive solution for data practitioners and researchers.

🔐 Key Features:
User Authentication
Secure Sign Up and Sign In functionality for personalized experiences.

Dataset Evaluation Engine
Evaluate datasets on various factors such as:

Bias detection

Class imbalance

Missing values

Label quality

Distribution metrics

Integrated LLM Chatbot
Embedded DeepSeek R1 (7B parameters) chatbot for intelligent interaction, dataset insights, and guided recommendations.

Downloadable Evaluation Report
Users can download detailed reports of dataset scores and insights in PDF/CSV format.

Suggested Improved Dataset
Based on evaluations, the system suggests an updated/improved version of the dataset for better model performance.

Sentiment Analysis on User Feedback
NLP-based feedback analysis system provides sentiment scores (Positive, Negative, Neutral) to understand user satisfaction.

Razorpay Payment Integration
Enables users to subscribe to different model tiers and dataset tools via Razorpay for a seamless and secure payment experience.
